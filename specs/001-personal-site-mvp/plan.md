# Implementation Plan: Personal Site MVP

**Branch**: `001-personal-site-mvp` | **Date**: 2026-06-01 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/001-personal-site-mvp/spec.md`

## Summary

Single-page personal site targeting technical recruiters at AI-first startups. Seven sections in fixed scroll order (Hero → About → Experience → Projects → Stack → Education & Languages → Contact), fully static, deployed to Vercel. Built with Next.js 15 (App Router, SSG) + Tailwind CSS v4 + Framer Motion. All content is TypeScript data constants — no CMS, no API, no server runtime.

## Technical Context

**Language/Version**: TypeScript 5 / Node 20

**Primary Dependencies**: Next.js 15, Tailwind CSS v4, Framer Motion, Geist font (next/font)

**Storage**: N/A — all content in `src/data/` TypeScript constants

**Testing**: N/A — no test suite configured

**Target Platform**: Modern browsers, 320px+ screens, dark mode only

**Project Type**: Static web app (SSG via Vercel)

**Performance Goals**: No JS blocking render for above-the-fold content. Animations ≤ 0.6s duration.

**Constraints**: No server runtime in production. No light mode. No inline styles. No CSS Modules.

**Scale/Scope**: ~6 sections, ~10–15 components, single developer.

## Implementation Phases

### Phase A — Project Bootstrap
1. Initialize Next.js 15 project with TypeScript, Tailwind v4, App Router, `src/` dir
2. Install Framer Motion and Geist font package
3. Configure `globals.css` with `@theme` tokens and dark base styles
4. Set up root `layout.tsx` with Geist Sans font variable and `color-scheme: dark`
5. Verify `npm run build` produces zero errors on empty page

### Phase B — Data Layer
6. Define TypeScript types (`ExperienceEntry`, `StackEntry`, `ContactLink`) in `src/data/`
7. Populate `experience.ts` with all work history entries (real content, not placeholders)
8. Populate `stack.ts` with all tech entries grouped by category
9. Populate `contact.ts` with email, LinkedIn, GitHub

### Phase C — Shared UI Primitives
10. Build `AnimatedSection` client component (Framer Motion `whileInView`, `once: true`)
11. Build `ToolTag` component (cyan-bordered pill)
12. Build `SectionHeading` component (consistent h2 style with mono font label)

### Phase D — Sections (in spec priority order)
13. **Hero** — name, title, tagline above the fold. Responsive on 320px+.
14. **About** — personal statement + professional intent paragraph.
15. **Experience** — reverse-chrono entries with company, role, dates, bullets, tool tags.
16. **Stack** — grouped by category (AI/ML → Backend → Frontend → Infra).
17. **Contact** — email (mailto), LinkedIn (new tab), GitHub (new tab).
18. **Projects** — intentional empty state. No broken layout.

### Phase E — Layout & Responsive Polish
19. Wire all sections into `page.tsx` in fixed order
20. Add optional sticky header with anchor nav links
21. Verify responsive layout at 320px, 768px, 1280px
22. Verify all animations complete ≤ 0.6s and don't block readability

### Phase F — Production Readiness
23. Run `npm run build` — zero errors required (SC-006)
24. Verify no horizontal overflow at 320px (SC-004)
25. Verify all contact links functional (SC-003)
26. Push to `main` → Vercel deploys automatically
